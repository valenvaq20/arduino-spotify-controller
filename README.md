# Arduino Spotify Controller

> 🇪🇸 Versión en español más abajo.

This project allows you to control Spotify playback using an Arduino Uno (or a compatible board), four push buttons, and a breadboard.

## Features

With this project you can:

* Play/Pause playback.
* Skip to the next track.
* Return to the previous track.

The Arduino communicates with a program running on the computer, which detects the button presses and sends the corresponding multimedia commands to control Spotify.

## Hardware Requirements

* Arduino Uno or compatible board.
* 4 push buttons.
* Breadboard.
* Dupont jumper wires.
* USB cable.

# 🇪🇸 Arduino Spotify Controller

Este proyecto permite controlar la reproducción de Spotify mediante un Arduino Uno (o una placa compatible), cuatro pulsadores (*push buttons*) y una placa de conexiones (*breadboard*).

## Funciones

Con este proyecto puedes:

* Pausar y reanudar la reproducción.
* Reproducir la siguiente canción.
* Reproducir la canción anterior.

La comunicación entre el Arduino y el ordenador se realiza mediante un programa que detecta las pulsaciones de los botones conectados al Arduino y envía los comandos multimedia correspondientes para controlar Spotify.

## Hardware necesario

* Arduino Uno o placa compatible.
* 4 pulsadores (*push buttons*).
* Breadboard (placa de conexiones).
* Cables Dupont.
* Cable USB para conectar el Arduino al ordenador.
